# xr-ai-interaction

Transport-neutral messages for a participant interacting with agents: user
queries, responses, presence, and interruption. Voice, routing, conversation,
and text front ends share these models without depending on voice media.

Refer to the
[xr-ai-interaction guide](https://nvidia.github.io/xr-ai/latest/reference/agent-sdk-interaction.html).
