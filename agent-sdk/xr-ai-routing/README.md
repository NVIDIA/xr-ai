# xr-ai-routing

Participant-scoped routing across application agents, with typed turn,
admission, answer, focus, and progress acknowledgment contracts.

Refer to the [conversation routing reference](https://nvidia.github.io/xr-ai/latest/reference/agent-sdk-routing.html)
for the routing flow, lifecycle, and API behavior.
