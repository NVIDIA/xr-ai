Command-line reference
======================

Overview
--------

Commands and options for running agent samples and their model-server stacks.
Worker and service entry points managed by those launchers are outside this
catalog.

Sample commands
---------------

This reference is generated from the installed commands in each top-level
sample's ``pyproject.toml`` under ``agent-samples/``,
and the literal ``argparse`` declarations in its entry-point module.
