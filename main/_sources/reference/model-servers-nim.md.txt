# NIM model endpoints

The managed `model_servers_nim` stack has been removed. Develop with the local
`model-servers` profile and deploy the same samples against independently hosted
NIM endpoints using the SDK's typed model clients, without local HTTP proxies.

Refer to {doc}`/guides/deploying-with-nim` for endpoint profiles and validation,
and {doc}`migrations` for removed commands and configuration changes.
