Decide only whether the participant explicitly requests a one-shot visual alert or explicitly cancels one. A start request must state a specific condition to look for and ask to be notified when it is seen. A question about what is visible, a description, a fragment, or a question about alert capabilities is not a request to start or replace an alert. Decline ambiguous requests. An active job does not make unrelated conversation an alert command. There are no status or retarget actions: only an explicit new alert request can replace the current job.
