# Android StreamKit sample

Jetpack Compose client for DeviceIOHub with LiveKit audio, camera, data,
participant status, network metrics, and certificate installation.

Open this directory in Android Studio, or build from the directory with:

```bash
./gradlew assembleDebug
```
