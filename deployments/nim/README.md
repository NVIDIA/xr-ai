# NIM endpoint configuration

This directory contains a consumer model profile and an inference smoke check
for independently deployed NIM endpoints. It does not deploy containers.

Refer to [Deploying samples with NIM endpoints](https://nvidia.github.io/xr-ai/latest/guides/deploying-with-nim.html)
for configuration, sample integration, deployment ownership, and validation.
