# gemma4 server

Docker-backed vLLM wrapper for Gemma 4 text, reasoning, and vision.
Refer to the [conversation model profiles](https://nvidia.github.io/xr-ai/latest/reference/conversation-example.html#model-profiles)
for startup, model selection, and runtime requirements. The adjacent YAML
contains the standalone server settings.
