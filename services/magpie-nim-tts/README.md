# Magpie NIM HTTP speech service

Expose a running Magpie Riva NIM through a Pocket-compatible HTTP speech API.
Refer to the [service guide](https://nvidia.github.io/xr-ai/latest/reference/magpie-nim-tts.html)
for startup, supported requests, streaming, and configuration.
