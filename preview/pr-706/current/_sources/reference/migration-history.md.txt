# Migration history

For the current release transition, refer to {doc}`migrations`. When skipping
releases, apply the archived guides in release order, then the current guide.
Each completed transition has its own guide named for its source and target
releases.

The notes through `v0.3.0-beta` are a cumulative legacy guide; their entries
were not separated by source release. They are preserved as published, with
links to that release's documentation.
