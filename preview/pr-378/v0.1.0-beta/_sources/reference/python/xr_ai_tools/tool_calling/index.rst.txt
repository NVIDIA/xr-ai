.. py:function:: handle_tool_call(call: xr_ai_models.ToolCall, tools: xr_ai_tools.tools.ToolSet) -> ToolCallResult

.. py:function:: run_tool_loop(messages: collections.abc.Sequence[xr_ai_models.ChatMessage], tools: xr_ai_tools.tools.ToolSet, call_model: ModelCallback, *, max_iterations: int = 4, max_tool_calls: int = 16) -> ToolLoopResult
   :async:


   Run one stateless, bounded model turn over native tools.

   The callback owns all model parameters and retry policy. The loop only
   supplies the current immutable transcript and the current turn's tool
   definitions. Calls in a model batch execute sequentially in emitted order.
