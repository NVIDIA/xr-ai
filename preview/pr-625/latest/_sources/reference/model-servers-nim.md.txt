# NIM model endpoints

The managed `model_servers_nim` stack has been removed. Develop with the sample-local
model stack and deploy the same samples against independently hosted
NIM endpoints using the SDK's typed model clients, without local HTTP proxies.

Refer to {doc}`/guides/deploying-with-nim` for endpoint profiles, validation,
and replacements for the removed commands and services.
