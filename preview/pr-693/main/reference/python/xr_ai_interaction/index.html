class xr_ai_interaction.ResponseOutput#

One complete response or one fragment of a streamed response.

A producer declares what kind of output it emits; the consumer decides when and how to render it, for example as speech or text. A reply answers one request. An update is unprompted information. A withdraw carries no content: it asks the consumer to drop the updates this producer queued for the participant that have not started playing.

Without response_id, this is a complete standalone response. Otherwise, ordered messages with the same participant, producer, and response_id form one streamed reply: append each message’s text until final=True closes it. The final message may contain text or be an empty terminator.

This model validates individual messages, not stream state. Consumers own stream tracking and their duplicate-handling policy.

Async context manager that publishes one reply, streamed or single.

Create it with ResponseOutputs.reply(). Every send() publishes one fragment of the reply, and leaving the context publishes the empty terminator that completes it. A single-message reply is one send.

  • Fragments that are blank before the first published fragment are skipped.

  • A canceled task never publishes: send raises asyncio.CancelledError when the current task is being canceled, even if the code it awaited swallowed the cancellation.

  • On exit, whether normal, by exception, or by cancellation, the terminator is published if any fragment was published and no publish failed. A failed publish is never retried or closed. Exceptions listed in the closed_errors of the ResponseOutputs are suppressed when they come from the terminator.

  • Calling send after the context exits raises RuntimeError.

property delivered: bool#

Whether the terminator was published; meaningful after the context exits.

class xr_ai_interaction.ResponseOutputs(
publisher: _Publisher,
topic: Any,
*,
source: str | None = None,
closed_errors: tuple[type[BaseException], Ellipsis] = (),
)#

Publish replies and updates without building protocol messages.

A producer declares what it emits. The consumer decides when it is rendered, so a producer never chooses interruption flags or stream identifiers.

Parameters:

  • publisher – Object with an async publish(topic, message, *, participant_id=...) method, such as AgentRuntime or RuntimeContext.

  • topic – Topic that carries ResponseOutput messages.

  • source – Producer name passed to publish as source. Omitted from the call when None.

  • closed_errors – Exception types that mean the consumer is already closed. Reply suppresses them when it publishes the terminator.
